# Table Block Sort

A WordPress plugin that adds sorting, search, CSV download, phone cards, a sticky header and more to the core Table block.

Load the `table-block-sort` skill (`.claude/skills/table-block-sort/SKILL.md`) before any work in this folder: it holds the layout,
the decisions, the design rules and the release steps. The two files below are always loaded.
